Overall Architecture
Application Type: Single-page application (SPA) for FDA Class II medical device control
Stack: React + TypeScript with Vite, Wouter routing, shadcn/ui components, Tailwind CSS
Theme: Light/dark mode toggle with professional medical device aesthetic

Real-Time Features
WebSocket Health System:
Global context provider tracks connection state
Exponential backoff retry: 250ms → 5000ms with jitter
Retry counter increments on each attempt, resets on success
StatusBar shows "Reconnecting… (N/∞)" banner when disconnected
No toast spam for connection issues
Live Telemetry:
10Hz updates for chronoamperometry data
Temperature/sensor data streamed via WebSocket
Ring buffer: Last 300 messages (30 seconds)
Smooth chart transitions
Subscribe to specific device on mount
Command Publishing:
Idempotent UI locks using useRef for persistent keys
Keys generated once per operation, cleared on ACK/NACK/TIMEOUT
Buttons locked during in-flight operations
Granular loading states: "Creating...", "Starting...", "Stopping..."
